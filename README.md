«ПР3. Ответы на контрольные вопросы» 
1.Разницы никакой нет.Оба варинта прибавляют 5 к x.Запись += 5 более краткая. 
2.x++ сначало использует старое значение,а потом увеличивает x.++x сначало увеличивает x,а потом использует новое значение. 
3.При сравнении (==, <, >= и т.д.) получается тип bool.Результат может быть только true или false. 
4.Короткое замыкание это когда программа не проверяет второе условие,если оно итак понятно. При || если первое условие истинно то второе не проверяется При && если первое условие ложно то второе не проверяется 
5.Приоритет в выражении 10-2*3 + 4/2.Сначало выполняются * и / а потом - и +.Получится 10-6+2=6 
6.Чтобы код было легче читать и понимать.Скобки показыают какую часть выражения нужно выполнять первой.
